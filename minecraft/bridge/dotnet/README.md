# Alternative Windows bridge

C# Windows bridge in `BondCraftBridge/`. The active minimal workflow in the documentation uses the [Python bridge](../python). This directory preserves the alternative implementation.

Build: `dotnet build BondCraftBridge/BondCraftBridge.csproj`. Connect the band through the [Android bridge](../../../apps/android/bridge) first. See the [main architecture](../../../docs/HOW_IT_WORKS.md).
